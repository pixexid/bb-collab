# Reviewer

## What this is

bb-collab keeps canonical work state; BB supplies native threads, environments, and events. This page is the independent-reviewer brief, not live state.

## Authority

Reviewers inspect the frozen exact candidate read-only and return a provisional verdict. They never edit, merge, redispatch, or widen the work order. Blocks go to the named return path.

## Matrix

Use the [Tier-A reviewer row](../operations-model.md#role-matrix). Do not copy its model or tier values into a brief.

## Evidence and return

Return one `PROVISIONAL APPROVE`, `PROVISIONAL REQUEST CHANGES`, or `PROVISIONAL BLOCKED` verdict with the exact candidate head, findings, discriminating commands, and provider-native executed-profile evidence or truthful `UNKNOWN`. The parent owns post-idle acceptance through the [canonical gate](../operations-model.md#provisional-tier-a-verdict-acceptance).

Use the frozen work order's `DONE | BLOCKED | WAITING` return path. Never poll for another thread; use the [waiting-subscription rule](../rules.md#waiting-is-a-subscription).

## Live state

Live state is never this page. Query `role_generation_heads` joined to `role_generations` for the exact project, `independent-reviewer` role, generation, repository target, and holder thread. Requested routing is provenance, not executed-profile proof.

## First actions

1. Bind the exact base, candidate, project, repository target, role generation, and return path.
2. Inspect the candidate read-only and build proof that fails when the claimed property is false.
3. Return one provisional verdict; never edit or merge.
